# python-file-organizer
A simple Python file organizer that sorts files into folders based on their extensions and generates a summary report.
My first Python portfolio project.

Description:
A simple file organizer that automatically sorts files into folders based on their extensions.

Features:
Organizes PDF and TXT files
Organizes images
Organizes ZIP archives
Organizes EXE applications
Moves other file types into a separate folder
Counts files and generates a summary report
Technologies
Python
pathlib
shutil

How to run:
1.Install Python.
2.Clone this repository.
3.Create a test_files folder next to the Python script.
4.Add files to the folder.
5.Run: 
 python file_organizer.py
